# Choosing Twitch sources

Reel Relay ships without a creator watchlist. Configure sources in **Setup & accounts → Sources** using Twitch usernames and accurate attribution. The current capture connector supports Twitch; a similarly named account on another service is not a substitute for the intended source.

Start with one live channel. Confirm that video and chat arrive, inspect the captured context and adjust timing before adding more channels. Each channel has its own chat baseline; a busy chat is not automatically a better source of worthwhile moments.

Choose sources you are entitled to capture and use. Preserve channel attribution and any required asset credits. The application does not verify repost permissions or grant rights to stream footage, games, music or third-party effects.

When comparing sources, measure candidates per hour, accepted edits, processing time and common reasons for holds or rejection. Raids, giveaways, repeated messages and off-topic chat can create spikes without an entertaining on-screen event. Include rejected and held candidates in the evaluation rather than considering only successful clips.

Public anonymous chat is experimental. Use the supported EventSub connection when authenticated chat access is needed. Do not treat an offline source, missing chat or a quiet queue as proof of an application failure; inspect the source health and activity records first.
